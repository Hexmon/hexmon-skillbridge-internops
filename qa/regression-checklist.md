# Regression Checklist

Run this before demo milestones and final presentation.

## Smoke

- [ ] Frontend installs successfully.
- [ ] Frontend starts locally.
- [ ] Backend installs successfully.
- [ ] `/health` returns `status: ok`.
- [ ] Main navigation pages open without blank screens.

## Feature Coverage

- [ ] F1 role directory content appears.
- [ ] F2 resources can be filtered.
- [ ] F3 task cards show owner, status, priority, and due week.
- [ ] F4 daily update form has labels and required fields.
- [ ] F5 mentor dashboard shows progress and blockers.
- [ ] F6 AI coach fallback works without an API key.
- [ ] F7 update summarizer returns a summary without an API key.
- [ ] F8 QA center shows cases and bug-report flow.
- [ ] F9 docs hub links to core docs.
- [ ] F10 final portfolio report has contribution evidence once implemented.

## Responsive And Accessibility

- [ ] Pages fit at mobile width.
- [ ] Keyboard tab order reaches form controls and buttons.
- [ ] Form fields have visible labels.
- [ ] Color contrast is readable.
- [ ] No content overlaps at desktop, tablet, or mobile widths.

## Release Decision

- [ ] Go
- [ ] Go with known issues
- [ ] No-go
