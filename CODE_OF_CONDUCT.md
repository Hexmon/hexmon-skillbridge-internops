# Code Of Conduct

This project should be a safe learning space for interns.

## Expected Behavior

- Be respectful and patient.
- Ask for help before staying blocked too long.
- Review pull requests with kindness and clarity.
- Credit teammates for their work.
- Keep feedback focused on the code, documentation, tests, or workflow.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Sharing secrets, credentials, or private information.
- Dismissing beginner questions.
- Merging risky changes without review.

## Reporting

If something blocks collaboration or makes the project unsafe, tell the mentor or project owner. The goal is to fix the situation quickly and fairly.
